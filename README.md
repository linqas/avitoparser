# Avito Radar

Локальное приложение для мониторинга публичных объявлений Avito и отправки уведомлений в Telegram.

Приложение работает с одним браузером и одним профилем. Запросы выполняются последовательно, без параллельного скрейпинга.

## Возможности

- несколько поисковых запросов со своими фильтрами;
- поиск по обычному запросу или по ссылке Avito с сохранением фильтров из URL;
- город, цена, доставка, обязательные и исключаемые слова;
- строгий и широкий режим модели;
- история цен и сравнение с рынком;
- избранное и чёрный список продавцов;
- уведомления в Telegram;
- задания из Telegram по ссылке Avito;
- первый полный снимок, затем только новые объявления и изменения цены;
- экспорт XLSX;
- CLI для Планировщика заданий Windows.

## Требования

- Windows 10/11, 64-bit;
- Python 3.12;
- доступ к Avito;
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).

Python 3.13 не подходит для `ddddocr`, который используется HTTP-режимом.

## Установка

Склонируйте репозиторий и перейдите в папку:

```powershell
git clone https://github.com/linqas/avitoparser.git
cd avitoparser
```

Создайте окружение и установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Установите Chromium для Playwright:

```powershell
python -m playwright install chromium
```

Если установка браузера в системную папку не удаётся, запустите:

```powershell
.\install_browser.bat
```

Скрипт сохранит браузер в `.playwright-browsers`, а временные файлы — в `.tmp`.

## Настройка

Создайте локальный конфиг из примера:

```powershell
copy config.example.toml config.toml
```

Откройте `config.toml` и заполните:

```toml
[telegram]
bot_token = "ТОКЕН_БОТА"
api_base = "https://api.telegram.org"
```

Реальный `config.toml` **не коммитится**: он содержит токен и добавлен в `.gitignore`.

После запуска отправьте боту `/start`, затем нажмите «Обновить список» в приложении и отметьте получателей.

## Запуск

```powershell
run.bat
```

`run.bat` использует локальную папку `python/`, если она есть, иначе `.venv312` или `.venv`.

CLI:

```powershell
run_cli.bat list
run_cli.bat run --once
run_cli.bat export exports\manual.xlsx
```

## Telegram-бот

Можно отправить боту ссылку Avito или команду:

```text
/add https://www.avito.ru/...
```

Затем выбрать режим кнопками:

- «Один раз» — полный снимок и завершение;
- «Каждые 15 минут»;
- «Каждые 30 минут»;
- «Каждые 60 минут».

Первый прогон присылает все подходящие объявления. Следующие циклы присылают только новые объявления и изменения цены.

Команды:

```text
/start     — подписаться на уведомления
/add URL   — добавить задание
/list      — список заданий
/status    — статус заданий
/stop 3    — остановить задание №3
/help      — помощь
```

Задания из Telegram выполняются только пока приложение запущено. Одновременно может работать только одно задание: либо ручной цикл приложения, либо задание из бота.

## Режимы приложения

- один прогон;
- N минут;
- цикл каждые N минут;
- до ручной остановки.

Первый цикл нового запроса запоминает текущую выдачу. Если включён снимок, он отправляется в Telegram; повторно те же объявления не отправляются.

## Портативная версия

GitHub хранит только исходный код.

Папки:

```text
python/
.playwright-browsers/
.browser-profile/
data/
```

в репозиторий не входят.

Для переноса готовой сборки на другой компьютер скопируйте папку проекта целиком вместе с `python/` и `.playwright-browsers/`. Профиль браузера при переносе можно не копировать — тогда Avito может попросить проверку заново.

## Важно

- не публикуйте `config.toml` с токеном;
- не запускайте несколько копий приложения одновременно;
- при капче приложение показывает браузер, проверку нужно пройти вручную;
- автоматическая капча работает только в HTTP-режиме и не гарантирует обход блокировки IP;
- уведомления и очередь заданий работают только при запущенном приложении.

## Структура

```text
main.py             — запуск приложения
gui.py              — интерфейс и MonitorWorker
scraper.py          — Playwright-сборщик
http_scraper.py     — HTTP-режим
avito_http/         — HTTP-клиент и решатели капчи
storage.py          — SQLite
filters.py          — фильтры запросов
notifier.py         — Telegram-уведомления
bot_listener.py     — команды Telegram
reporter.py         — таблица и XLSX
config.example.toml — пример конфигурации
```

## Ограничения

Проект предназначен для личного использования. Соблюдайте правила Avito и законодательство своей страны. Автор не гарантирует бесперебойную работу при изменениях сайта или блокировках.
