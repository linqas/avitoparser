# Avito Radar

Локальное приложение для мониторинга публичных объявлений Avito и отправки уведомлений в Telegram.

Проект рассчитан на личное использование. Один браузер, один профиль, последовательные запросы без параллельного скрейпинга.

## Возможности

- несколько поисковых запросов со своими фильтрами;
- поиск по обычному запросу или по ссылке Avito с сохранением фильтров из URL;
- город, цена, доставка, обязательные и исключаемые слова;
- строгий и широкий режим модели;
- история цен и сравнение с рынком;
- избранное и чёрный список продавцов;
- уведомления в Telegram;
- новые запросы из Telegram по ссылке;
- первый полный снимок, затем только новые объявления и изменения цены;
- защита от повторной отправки;
- экспорт XLSX;
- CLI для Планировщика заданий Windows.

## Требования

- Windows 10/11, 64-bit;
- Python 3.12;
- доступ к Avito;
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).

Python 3.13 не подходит для `ddddocr`, который используется HTTP-режимом.

## Установка

```powershell
git clone https://github.com/linqas/avitoparser.git
cd avitoparser
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m playwright install chromium
```

Если браузер не ставится в системную папку:

```powershell
.\install_browser.bat
```

Скрипт сохранит Chromium в `.playwright-browsers`, а временные файлы — в `.tmp`.

## Настройка

Создайте локальный конфиг:

```powershell
copy config.example.toml config.toml
```

Заполните Telegram:

```toml
[telegram]
bot_token = "ТОКЕН_БОТА"
api_base = "https://api.telegram.org"
```

`config.toml` содержит секреты и не коммитится — он добавлен в `.gitignore`.

После запуска отправьте боту `/start`, затем назначьте владельца в настройках приложения.

## Запуск

```powershell
run.bat
```

`run.bat` использует локальную папку `python/`, если она есть, иначе `.venv312` или `.venv`.

CLI:

run_cli.bat list
run_cli.bat run --once

## Telegram-бот

После `/start` внизу чата остаётся клавиатура:

```text
[Новый запрос] [Мои запросы]
[Статус]       [Сводки]
[Помощь]       [Свернуть меню]
```

«Свернуть меню» скрывает клавиатуру и показывает inline-кнопку «Развернуть меню».

### Доступ

Владелец назначается в настройках приложения, в блоке получателей.

Создавать запросы могут:

- владелец;
- подписчики с галочкой «Может создавать запросы».

Остальные получают сводки, но не могут создавать запросы. Пока владелец не назначен, создание запрещено.

### Новый запрос

1. Нажмите «Новый запрос».
2. Пришлите ссылку Avito.
3. Выберите режим:
   - один раз;
   - каждые 15 минут;
   - каждые 30 минут;
   - каждые 60 минут;
   - свой интервал от 1 до 1440 минут.

Первый цикл присылает полный снимок: город и вся Россия, без дублей. Следующие циклы — только новые объявления и изменения цены.

### Управление запросами

В разделе «Мои запросы»:

- «Стоп» — остановить;
- «Интервал» — изменить периодичность;
- «Заново» — поставить в очередь снова;
- «Ссылка» — открыть исходную ссылку.

Номера запросов в сообщениях не показываются.

### Статус

`/status` показывает:

- выполняется ли цикл;
- какой запрос;
- длительность;
- очередь;
- следующий запуск.

Кнопка «Обновить» обновляет сообщение.

### Сводки

`/digests` показывает последние 10 сводок.

- «Закрыть» убирает клавиатуру, но не удаляет сводку;
- сводку можно открыть заново;
- «Мой город» ставит объявления из города запроса первыми;
- режим сохраняется при перелистывании и смене сортировки.

### Команды

```text
/start     — подписаться и открыть меню
/add URL   — добавить запрос
/list      — мои запросы
/status    — статус
/digests   — последние сводки
/stop      — остановить текущий запрос
/help      — помощь
```

## Стратегии капчи

Выбор доступен в настройках приложения **только** при методе:

```text
Авто: HTTP → браузер
```

Варианты:

### Как сейчас (legacy)

- HTTP;
- при неудаче — браузер;
- без новых правил;
- после ошибки пауза 5 минут.

### Ручная + авто

- HTTP пытается автоматически;
- при проверке открывается браузер;
- после ручного прохождения cookies передаются в HTTP;
- дальше автоматические попытки;
- после неудачи пауза 10 минут;
- после трёх неудач — тихое уведомление в Telegram;
- попытки продолжаются.

### Только авто

- браузер не открывается;
- HTTP пытается автоматически;
- после неудачи пауза 10 минут;
- после трёх неудач — тихое уведомление;
- попытки продолжаются.

Настройки:

```toml
[scraper]
captcha_strategy = "legacy"  # legacy | manual_then_auto | auto_only
captcha_retry_minutes = 10
captcha_fail_alert_after = 3
```

Тихие уведомления отправляются с:

```text
disable_notification = true
```

Гарантии обхода капчи или IP-блока нет. Режимы повышают устойчивость, но не отменяют ограничения Avito.

## Поиск по городу

Для обычных запросов с городом:

1. выполняется поиск по городу;
2. затем по всей России;
3. результаты объединяются;
4. дубликаты удаляются;
5. городские объявления идут первыми.

Для точных ссылок Avito фильтры из URL не меняются.

## Сортировка таблицы

Доступна сортировка:

```text
По размеру скидки
```

Сначала показываются объявления с наибольшей выгодой относительно рынка.

## Режимы приложения

- один прогон;
- N минут;
- цикл каждые N минут;
- до ручной остановки.

После успешного цикла пауза равна заданному интервалу. После ошибки — отдельная пауза: 10 минут для новых стратегий, 5 минут для legacy.

## Портативная версия

GitHub хранит только исходный код.

Не входят в репозиторий:

```text
python/
.playwright-browsers/
.browser-profile/
data/
config.toml
```

Для переноса готовой сборки скопируйте папку целиком вместе с `python/` и `.playwright-browsers/`. Профиль браузера можно не переносить — тогда Avito может попросить проверку заново.

Не публикуйте `config.toml`: в нём токен и API.

## Структура

```text

avito_http/         — HTTP-клиент, PoW, QRATOR, GeeTest
storage.py          — SQLite
filters.py          — фильтры запросов
notifier.py         — Telegram-уведомления
bot_listener.py     — команды и меню Telegram
reporter.py         — таблица и XLSX
config.example.toml — пример конфигурации
```

## Ограничения

Проект предназначен для личного использования. Соблюдайте правила Avito и законодательство своей страны. Автор не гарантирует бесперебойную работу при изменениях сайта или блокировках.
