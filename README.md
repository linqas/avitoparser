# Avito Radar

Локальное десктопное приложение на Python для мониторинга публичных объявлений Avito.
Интерфейс и журнал — на русском языке. Уведомления отправляются в Telegram выбранным
получателям, которые отправили боту `/start`.

Приложение **не использует прокси для Avito, веб-интерфейс и параллельный скрейпинг**.
Playwright запускает Chromium с отключённым системным прокси. По умолчанию окно скрыто
за пределами экрана и показывается только при проверке Avito. Chromium остаётся отдельным
процессом (встроить его внутрь окна CustomTkinter нельзя), поэтому в панели задач может
оставаться его иконка. Страницы и поисковые запросы обрабатываются строго последовательно,
между действиями выдерживается пауза 5–10 секунд. Для Telegram по умолчанию используется прямое подключение;
если `api.telegram.org` заблокирован, можно подключить собственный Cloudflare Worker
(см. раздел про Telegram).

## Возможности

- один или несколько поисковых запросов, у каждого — **свои** фильтры;
- город, диапазон цены, Авито Доставка, обязательные и исключаемые слова;
- вставка ссылки Avito с сохранением категории и исходных фильтров;
- перехват JSON-выдачи Avito (`/web/1/js/items`) для быстрых дат, цен и бейджей доставки; DOM остаётся запасным вариантом;
- переключатель Avito «Сначала в выбранном городе» для каждого запроса;
- запросы и их фильтры сохраняются в SQLite и восстанавливаются после перезапуска;
- режимы: один прогон, N минут, цикл каждые N минут, до ручной остановки;
- первый цикл нового запроса запоминает текущую выдачу без уведомлений;
- в уведомления не попадают объявления старше `[app].fresh_hours` (по умолчанию 3 часов);
- свой лимит объявлений для каждого запроса;
- подписчики Telegram через `/start`, выбор получателей чекбоксами;
- одна сводка на запрос с кнопками «Показать» и «Скачать XLSX» вместо сообщения на каждый лот;
- сравнение с SQLite: новые объявления, изменение цены, возможное снятие с публикации;
- колонка «От рынка» и сортировка «%Выгоды от рынка»;
- автоматический подбор числа страниц под лимит объявлений;
- настройка количества карточек для точной даты;
- строгий/широкий режим модели, активные/отключённые запросы и копирование запроса;
- фильтр продавца: любой / только частные / только компании;
- панель объявления справа: цена, рынок, продавец, история цены, избранное и чёрный список продавца;
- колонка ★ и фильтр «Избранное» в таблице;
- окно «Чёрный список» с разблокировкой продавцов;
- «Подробнее» в контекстном меню таблицы;
- кнопка «Проверить» — один пробный запрос с причинами отказа;
- быстрый поиск по готовой таблице;
- per-query уведомления: новые, цена, старые;
- CLI `cli.py` и `run_cli.bat` для Планировщика заданий Windows;
- история цен, экспорт XLSX и сортируемая таблица в окне;
- отдельная группа объявлений без цены, если в выдаче есть обе группы;
- счётчики цикла и вкладка «Не подходящие» с причинами по каждой карточке;
- обработка капчи/блокировки, пустой выдачи, ошибок страницы и неверного Telegram-токена.

## Установка (Windows, Python 3.12)

```powershell
cd C:\Users\1\Downloads\parser
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m playwright install chromium
```

Если Chromium не устанавливается в `AppData` с ошибкой `EPERM` (частая проблема при
ограниченных правах Windows), запустите из папки проекта:

```powershell
.\install_browser.bat
```

Скрипт сохранит Chromium в `.playwright-browsers` внутри проекта, а временные файлы — в
`.tmp`. Приложение автоматически находит этот браузер через `scraper.py`.

Если PowerShell не разрешает активацию окружения:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## Настройка

1. Откройте `config.toml`.
2. Проверьте пути и лимит:
   - `[app].max_listings = 50` — лимит по умолчанию для новых запросов; в карточке
     каждого запроса его можно изменить;
   - `[scraper].action_pause_min/max` — паузы, не делайте их меньше 5 секунд;
   - `[scraper].scan_limit = 50` — сколько карточек просматривать на странице,
     чтобы отобрать N подходящих;
   - `[scraper].captcha_wait_seconds = 0` — 0 означает ждать проверку Avito без
     ограничения по времени; положительное число задаёт таймаут;
   - `[scraper].transport` — `auto`, `http`, `browser` или `aggressive`;
   - `[scraper].auto_captcha = true` — автоматически решать капчу HTTP-движком;
   - `[scraper].hidden_window = true` — держать Chromium за пределами экрана;
   - `[scraper].show_on_captcha = true` — показывать скрытое окно при проверке;
   - `[scraper].enrich_missing_dates = true` — открывать карточку объявления,
     если в выдаче нет точной даты (медленнее, но точнее);
   - `[scraper].date_lookup_pause_min/max = 1/2` — короткая пауза между
     карточками для уточнения даты; обычная пауза поиска не меняется;
   - даты отображаются в **системном часовом поясе Windows**;
   - `[app].fresh_hours = 3.0` — не присылать новые объявления старше этого возраста;
     `0` отключает проверку.
   - `[app].date_enrich_limit = 5` — максимум карточек за цикл, которые открываются
     ради точной даты. `0` отключает такие открытия.
3. Для Telegram впишите токен одним из двух способов:
   - в поле **«Токен бота»** в приложении: вставьте через **«Вставить»** или `Ctrl+V`
     и нажмите **«Сохранить токен»**;
   - если вставка в GUI не срабатывает, нажмите **«Открыть config.toml»**, впишите токен
     в `[telegram].bot_token`, сохраните файл и перезапустите приложение.

Под блоком «Получатели» отображается состояние слушателя Telegram: «токен не задан»,
«подключаюсь», «подключён, бот @...» или ошибка. Пока токен не сохранён, слушатель `/start`
не работает, поэтому список получателей останется пустым — это не ошибка обновления списка.

Токен нигде не захардкожен. Он не выводится в журнал и не попадает в XLSX; сетевое
исключение с токеном в тексте автоматически редактируется. Не передавайте свой
`config.toml` другим людям и не коммитьте его с реальным токеном.

### Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и вставьте токен в приложение.
2. Отправьте боту `/start` с каждого аккаунта, который должен получать уведомления.
3. Нажмите **«Обновить список»** в блоке «Получатели».
4. Отметьте нужные `@username` чекбоксами.

У пользователя без публичного username в списке будет `@id<chat_id>`. Бот отвечает на
`/start` подтверждением на русском. Если получатель заблокировал бота, приложение
покажет ошибку в GUI и журнале, но не остановит сбор.

В настройках Telegram можно указать:

- **API Telegram** — `https://api.telegram.org` или базовый URL Cloudflare Worker
  (до `/bot<TOKEN>/...`);
- **Прокси** — необязательный `http://`, `https://` или `socks5://` адрес.

В разделе **«Уведомления в Telegram»** можно включить новые объявления,
изменения цены, старые объявления, ограничить максимальную цену, задать
ключевые слова и выбрать сортировку дайджеста: дата, цена или выгода.
Теперь бот присылает тот же снимок, что и таблица, а в самом дайджесте
есть кнопки **«Дата / Цена / Выгода»**; выбор запоминается для чата.

### Сводки уведомлений

На каждый поисковый запрос приходит **одно сообщение-сводка**, а не отдельное сообщение
на каждое объявление:

- новые, изменения цены и снятые сгруппированы по разделам;
- кнопка **«Показать»** раскрывает по 10 объявлений, дальше — «Ещё» / «Назад»;
- кнопка **«Скачать XLSX»** присылает файл со всеми объявлениями сводки;
- данные сводки хранятся 7 дней;
- нажимать кнопки может только получатель, которому была отправлена сводка.

Так 50 новых объявлений превращаются в одно сообщение и несколько страниц по кнопке.

### Если `api.telegram.org` недоступен

В России Telegram Bot API может не отвечать напрямую: в журнале будут `ConnectTimeout`
или `Connection reset`. VPN здесь помогает не всегда, а системный прокси приложение не
использует. Для этого добавлен готовый **собственный Cloudflare Worker**:
[cloudflare-worker/README.md](cloudflare-worker/README.md).

Схема:

```text
Avito Radar -> https://<worker>.workers.dev/<PROXY_SECRET>/bot<TOKEN>/...
            -> https://api.telegram.org/bot<TOKEN>/...
```

Короткая инструкция:

1. Создайте бесплатный аккаунт Cloudflare.
2. Workers & Pages → Create application → Hello World → Deploy.
3. Вставьте код из [cloudflare-worker/worker.js](cloudflare-worker/worker.js) и задеплойте.
4. Добавьте секрет `PROXY_SECRET` и, желательно, `ALLOWED_BOT_ID` в настройках Worker.
5. В `config.toml` укажите:
   ```toml
   [telegram]
   api_base = "https://<worker>.workers.dev/<PROXY_SECRET>"
   ```
6. Перезапустите приложение.

Worker принимает только запросы к `api.telegram.org` и только с секретным путём. Не
используйте публичные прокси: они получают доступ к токену бота. Готовые Worker-прокси
для Bot API существуют и как сторонние проекты, например
[tgwsapiproxy](https://pypi.org/project/tgwsapiproxy/) и
[tg-bot-ws-proxy](https://github.com/tvoklov/tg-bot-ws-proxy), но здесь приложен
минимальный собственный вариант без сторонних зависимостей.

## Запуск

Из PowerShell:

```powershell
python main.py
```

Или просто дважды щёлкните `run.bat` в папке проекта — он использует `.venv` и не требует
активации окружения.

Порядок работы:

1. В приложении загружается `config.toml`, открывается SQLite-база и запускается слушатель
   Telegram (если токен задан).
2. Добавьте запрос через поле «Запрос или ссылка Avito». Можно вставить обычный запрос
   или полную ссылку Avito. Если `Ctrl+V` или правая кнопка мыши не срабатывают,
   используйте кнопку **«Вставить»** — она читает буфер обмена напрямую.
   У появившейся карточки раскройте фильтры: город, цена,
   доставка, обязательные/исключаемые слова и лимит объявлений.
   При необходимости включите **«Сначала в выбранном городе»**.
3. Настройки карточки сохраняются автоматически. Свёрнутая карточка показывает краткую
   сводку выбранных фильтров.
4. Выберите режим в выпадающем списке — описание режима отображается рядом.
   Поле интервала показывается только для циклических режимов.
5. Выберите получателей.
6. Нажмите **«Старт»**. Chromium запустится скрыто; окно появится только если
   Avito потребует проверку. Кнопки **«Стоп»** и **«Показать»** появляются только
   во время работы.
7. Наблюдайте за журналом и таблицей справа. Над таблицей показываются счётчики
   «найдено / подходит / отклонено», а во вкладке «Не подходящие» — причины отказов.
8. **«Стоп»** прерывает текущий цикл и ожидание следующего.

После каждого цикла автоматически обновляется `exports/avito_radar_auto.xlsx`.
Если были неподходящие карточки, в XLSX появляется лист «Не подходящие».
Кнопка **«Экспорт XLSX»** сохраняет файл в выбранное место. Кнопка **«Открыть лог»**
открывает `logs/avito_radar.log`.

## Демо-режим без сети и Telegram

```powershell
python main.py --demo --limit 5
```

Демо использует отдельную базу `data/demo_avito_radar.db` и не обращается к Avito,
Telegram и токену бота. Оно показывает полный локальный пайплайн: нормализацию карточек
(включая относительные даты), фильтры, сравнение, историю цен, группу без цены и XLSX.
Файл сохраняется в `exports/demo_avito_radar.xlsx`. Первый запуск показывает новые
объявления, повторный — изменение цены iPhone; для сброса удалите
`data/demo_avito_radar.db`.

## Проверка живого сборщика (5 карточек)

```powershell
python scraper.py --query "iPhone 13" --city "Москва" --limit 5
```

Скрипт откроет Chromium с той же настройкой скрытого окна, дождётся страницы, выведет
до 5 нормализованных словарей в консоль и закроет браузер. Это тест селекторов и доступа
к Avito, а не работа всего приложения.

## Режимы

| Режим | Поведение |
|---|---|
| один прогон | один цикл, затем остановка |
| N минут | циклы подряд в течение N минут (поле «Длительность, минут»), затем автоматический выход |
| цикл каждые N минут | цикл, перерыв N минут, повтор до ручной остановки |
| до ручной остановки | цикл, перерыв N минут, повтор до нажатия «Стоп» |

Поле интервала скрыто для «одного прогона» и показывается для трёх циклических режимов.
В режиме N минут между циклами остаются обязательные паузы Playwright, поэтому частых
запросов нет.

Первый цикл **нового** запроса запоминает текущую выдачу и не присылает уведомления —
это защита от лавины старых объявлений. Существующие запросы при обновлении приложения
считаются уже подготовленными. В Telegram не попадают новые объявления старше
`[app].fresh_hours` (по умолчанию 3 часа); `0` отключает проверку.

## Фильтры каждого запроса

Общее правило: **пустое поле не ограничивает поиск**. Под фильтрами есть подсказка,
у города — отдельная подпись «Пусто — поиск по всей России». Если город не указан,
в свёрнутой карточке отображается «Вся Россия».

Общих фильтров над списком больше нет: каждое условие относится только к своей карточке
запроса. Это позволяет, например, искать «iPhone 15» в Кургане до 60 000 ₽ и одновременно
«MacBook Air» по всей России без ограничения цены.

- **Город** — передаётся в поиск Avito и определяется по URL объявления
  (`/moskva/...` → Москва), а не по станции метро из карточки. Сравнение регистронезависимо:
  «Москва», «москва» и «г. Москва» работают одинаково. Локальная проверка мягкая: явно
  чужие города отбрасываются, а карточки без города остаются. Станция метро или район
  показывается как уточнение: «Москва · м. Смоленская».
- **Сначала в выбранном городе** — добавляет в поиск Avito штатный параметр
  `localPriority=1`; Avito сам поднимает объявления выбранного города. Опция действует
  только при заполненном городе.
- **Цена от/до** — локальная проверка. Объявление без цены не проходит фильтр, если задана
  хотя бы одна граница.
- **Авито Доставка**:
  - `есть` — только карточки, где доставка явно найдена;
  - `нет` — исключить карточки с Авито Доставкой;
  - `не важно` — не фильтровать.

- **Обязательные слова** — через запятую. Должны встречаться **все** слова в заголовке.
- **Исключаемые слова** — через запятую. Достаточно любого совпадения, чтобы отклонить
  карточку.
- **Объявлений за прогон** — выпадающий список 5/10/20/30/50 с возможностью ввести своё
  число. Это количество **подходящих после фильтров** объявлений. Приложение просматривает
  до 50 карточек страницы и отбирает из них подходящие; если их меньше N, вернётся меньше.
- **Страницы подбираются автоматически**: нужно 130 объявлений при 50 на странице —
  будет открыто 3 страницы. Отдельного ручного выбора страниц больше нет.
- **Сортировка Авито** — по умолчанию, по дате, цена ↑ или цена ↓; задаётся
  отдельно для каждого запроса и влияет на то, какие объявления попадут в первые 50.
- HTTP-клиент сохраняет cookies после успешной сессии и после ручной проверки,
  чтобы следующие запуски реже упирались в капчу.
- Проверка снятия с публикации по умолчанию выключена (`[app].missing_check = false`),
  чтобы не было ложных «снято» при неполном проходе страниц.
- **Модель из запроса** — дополнительно проверяется по заголовку: запрос
  «iphone 15 pro» не пропустит iPhone 15 Pro Max, iPhone 15 или iPhone 14 Pro.
  Понимаются частые русские варианты: «ыпхоне» → iPhone, «про» → Pro и т.п.
- **Ссылка Avito** — если вставить ссылку в поле нового запроса, сохраняются категория и
  закодированные фильтры `f=...`. Город, цена и `localPriority` извлекаются в поля и могут
  быть переопределены; название запроса служит только подписью и не меняет исходную ссылку.
  Пустое поле не стирает параметр ссылки, а оставляет исходное значение. Кнопка
  «Очистить ссылку» переключает карточку на обычный поиск по полям.
- Поиск и сравнение слов не учитывают регистр и разницу `ё`/`е`.

Все неподходящие карточки не пропадают бесследно: они видны во вкладке «Не подходящие»
с запросом и конкретной причиной. В XLSX они выгружаются на отдельный лист.

## Таблица результатов

- Таблица «Подходящие» показывает **только текущий цикл**, а не все объявления, когда-либо
  сохранённые в базе. Поэтому старые результаты из других городов больше не смешиваются
  с новой выдачей. Счётчик «В базе» в журнале по-прежнему показывает всю историю SQLite.
- В «Подходящих» есть колонка **«От рынка»**, значение берётся из аналитики рынка.
- Строки подсвечиваются по выгоде: зелёный — заметно дешевле рынка, красный — дороже.
- В аналитике рынка убрана группировка по модели/памяти, остались заголовки объявлений.
- Колонка просмотров убрана: Avito не отдаёт её в поисковой выдаче.
- Сортировка **«%Выгоды от рынка»** ставит первыми объявления с наибольшей скидкой
  относительно медианы; такая же сортировка доступна на вкладках аналитики и отклонённых.
- Колонка «Статус» из «Подходящих» убрана.
- Колонки **«ID»** больше нет ни в таблицах, ни в XLSX; ID остаётся только в базе.
- Левый столбец **«Ссылка»** — клик по «Открыть» запускает объявление в браузере
  пользователя по умолчанию (через `os.startfile` / `webbrowser`).
- **«Открыть выбранное»** над таблицей и двойной клик по строке открывают выбранное
  объявление. Если открыть не удалось, показывается сообщение, а ссылка копируется
  в буфер обмена.
- Правая кнопка мыши по строке открывает меню **«Открыть объявление» / «Копировать ссылку»**.
- `Ctrl+C` на выбранной строке тоже копирует ссылку.
- В колонке «Город» отображается город и, если Avito его показал, метро/район.
- Заголовки `С ценой` / `Без цены` показываются только когда в таблице есть обе группы.
  Если все объявления с ценой, список выводится без групповых надписей.
- Тип продавца больше не определяется и не фильтруется.
- «Просм.» показывает число просмотров, а при отсутствии данных — **«нет»**.
- Ссылка в XLSX остаётся кликабельной; лист «Не подходящие» также сохраняется.
- В XLSX нет колонки продавца, зато город показан вместе с метро/районом.
- Скроллбары таблицы оформлены в том же стиле, что и прокрутка левой панели.

## Интерфейс

По умолчанию `run.bat` запускает новый **PySide6/Qt**-интерфейс без мерцания Tk.
Старый CustomTkinter-вариант сохранён для отката:

```bat
run_classic.bat
```

Qt-версия использует те же `config.toml`, SQLite, HTTP/Playwright, фильтры,
Telegram и планировщик. Отдельный запуск: `run_qt.bat`.

## CLI и планировщик

Кроме окна, есть headless-режим:

```bat
run_cli.bat list
run_cli.bat run --once
run_cli.bat run --once --no-telegram
run_cli.bat export exports\manual.xlsx
run_cli.bat add "https://www.avito.ru/..."
```

`run --once` выполняет один цикл и завершается. Это удобно для Планировщика заданий
Windows: действие — `run_cli.bat`, аргументы — `run --once`, рабочая папка — папка проекта.
Так приложение не должно быть открыто, а запуск можно ставить по расписанию.
Прокси не используются; при одном IP не запускайте несколько копий одновременно.

## Метод парсинга

В настройках приложения есть переключатель:

- **Авто: HTTP → браузер** — рекомендуется. Сначала быстрый HTTP, при капче
  автоматическое решение, при неудаче — обычный Chromium с ручной проверкой.
- **HTTP: быстро** — только внутренний JSON Avito через `curl_cffi`; окно не
  открывается.
- **Браузер: безопасно** — обычный Playwright с ручной капчей.
- **Агрессивный HTTP** — без отката на браузер; предназначен для будущих
  прокси и параллельных воркеров.

Метод сохраняется в `config.toml`:

```toml
[scraper]
transport = "auto"
auto_captcha = true
http_delay_seconds = 10.0
```

`auto_captcha` включает автоматическое решение капчи HTTP-движком. В браузерном
режиме капча всё равно проходится вручную.

Для авто-капчи нужен Python 3.12: `ddddocr` не поддерживает 3.13. Запускайте
`run.bat` — он выбирает `.venv312`.

## Аналитика рынка

Вкладка **«Аналитика рынка»** сравнивает активные объявления из SQLite по группам
«модель + память»:

- медиана, квартили и отклонение цены от рынка;
- группы меньше трёх объявлений не считаются рынком;
- выбросы отбрасываются;
- по заголовку отмечаются «битый / на запчасти» и «подозрительно дёшево»;
- двойной клик по строке открывает объявление.

Это работает для товаров, у которых в заголовке есть модель и объём памяти. Для
недвижимости и произвольных категорий группировка может быть неточной.

## Что сохраняется

Таблицы SQLite:

- `saved_queries` — поисковые запросы, фильтры и признак первого цикла;
- `listings` — последнее состояние объявления, статус `active`/`missing`;
- `price_history` — цена и время наблюдения;
- `seen_ids` — связь «поисковый запрос + фильтры → объявление» для поиска исчезновений;
- `subscribers` — `chat_id`, `@username`, имя, время подписки.

Поля объявления: `id`, заголовок, цена (`None`, если не указана), абсолютная дата публикации,
город, метро/район, доставка (`yes`/`no`/`unknown`), URL, просмотры (если есть).
Относительные даты («вчера», «3 часа назад») преобразуются в ISO 8601 по московскому
времени. Для отображения используется системный часовой пояс компьютера.
Уже сохранённые в SQLite точные даты и доставка повторно не запрашиваются: они используются
как кэш, поэтому повторные циклы не открывают те же карточки снова.
Сначала приложение перехватывает JSON-ответ поисковой выдачи Avito и берёт дату,
цену и бейджи доставки оттуда. Если JSON не пришёл или в нём нет даты, открываются
только подходящие карточки — не больше `date_enrich_limit` за цикл; это медленнее и
может потребовать ручной проверки Avito. В первом цикле нового запроса карточки
для дат не открываются вообще.
Если дату не удалось найти даже в карточке, в таблице остаётся «неизвестно».
При обновлении существующей базы колонки `metro`, `local_priority`, `max_listings`
и `source_url` добавляются автоматически, а город у старых записей восстанавливается из URL
объявления. Поле `source_url` хранит исходную ссылку Avito, если запрос был добавлен из неё.

## Крайние случаи

- **Объявление без цены** — попадает в отдельную группу таблицы (если есть и объявления
  с ценой) и на отдельный лист XLSX «Без цены»; в сортировке по цене не участвует.
- **Поле доставки отсутствует** — сохраняется `unknown`, в интерфейсе «неизвестно».
  Avito показывает признак Авито Доставки не на каждой карточке; если его нет, приложение
  не угадывает «есть/нет». Если доставка уже была сохранена в базе, она подставляется из кэша.
- **Ошибка страницы / прокрутки** — уже собранные объявления сохраняются, ошибка пишется в лог
  и отправляется выбранным получателям; проверка исчезновений в этом цикле пропускается,
  чтобы не создать ложные уведомления.
- **Капча или блокировка Avito** — приложение оставляет Chromium открытым и при
  `captcha_wait_seconds = 0` ждёт проверку без ограничения по времени. Скрытое окно
  автоматически показывается на экране, чтобы вы могли пройти слайдер/пазл; после
  прохождения оно снова скрывается, и сбор продолжается. Для выхода из ожидания нажмите
  **«Стоп»**. Если задать положительное число, по истечении таймаута цикл пропускается,
  делается скриншот в `logs/screenshots` и отправляется уведомление о блокировке.
- **HTTP 429/403 со страницей «Страница не загрузилась из-за проблем с IP»** —
  это не слайдер, а ограничение IP. Приложение теперь тоже показывает окно и ждёт:
  нажмите **«Пройти проверку»** в браузере, при необходимости пройдите слайдер.
  Если проверка не появляется, подождите 15–60 минут и не перезапускайте сбор подряд.
- **Кнопка «Показать» / «Скрыть»** рядом со «Стоп» — переключает видимость
  Chromium во время работы, в том числе в перерыве между циклами. Подпись
  обновляется автоматически, в том числе когда окно показывает сама программа
  при проверке Avito. После проверки автоматически показанное окно скрывается,
  а показанное вручную остаётся, пока вы не нажмёте «Скрыть».
- **Ничего не найдено** — запись в лог, приложение продолжает работу.
- **Все найденные карточки отклонены фильтрами** — таблица «Подходящие» остаётся пустой,
  но счётчики показывают «найдено / отклонено», а вкладка «Не подходящие» объясняет причину
  по каждой карточке. Причина также пишется в журнал и XLSX.
- **Неверный Telegram-токен или chat_id** — ошибка в журнале и модальное сообщение в GUI;
  сам сбор не прерывается.
- **Нет связи с `api.telegram.org`** — слушатель не получает `/start`, но повторяет
  подключение каждые 30 секунд. Для заблокированных сетей используйте собственный
  Cloudflare Worker из `cloudflare-worker/` и задайте `[telegram].api_base`.
- **Цена не прочиталась у уже известного объявления** — сохраняется прежняя цена, чтобы не
  создавать ложное «изменение цены».
- **Одинаковые объявления в нескольких запросах** — не дублируются в `listings`; исчезновение
  проверяется по каждому запросу, но глобально «снятым» объявление становится, только если
  его больше нет ни в одном активном запросе.

## Если Avito показывает проверку браузера

Avito использует GeeTest v4 (слайдер/пазл) и ограничивает доступ по IP, VPN и признакам
автоматизации. В HTTP/Auto-режиме приложение пробует автоматическое решение через
`GeekedTest`; при неудаче переходит в Chromium, где проверку можно пройти вручную.
Авто-капча отключается галочкой в настройках. Что делать:

1. Проверьте Avito в обычном Chrome на этом же компьютере. Если сайт недоступен и там,
   ограничение внешнее: отключите VPN, проверьте сеть, подождите либо смените интернет.
2. Если обычный Chrome работает, при появлении капчи или страницы «Пройти проверку»
   приложение само покажет скрытый Chromium. Нажмите «Пройти проверку» и пройдите
   слайдер/пазл вручную; после прохождения окно снова скроется, и сбор продолжится.
   Ожидание по умолчанию не ограничено — выход через «Стоп». Если окно не появилось,
   нажмите кнопку **«Показать»** рядом со «Стоп».
3. Не запускайте сбор много раз подряд: Avito может усилить ограничение.
4. Профиль Chromium сохраняется в `.browser-profile`, поэтому Cookie и результат проверки
   используются при следующих запусках. Это снижает частоту проверок, но не гарантирует
   их отсутствие.

## Селекторы Avito и запасной вариант

Avito периодически меняет разметку. Сборщик использует несколько уровней поиска:
`[data-marker="item"]`, `[data-marker="item-title"]`, `[data-marker="item-price"]`,
`[data-marker="item-date"]`, `[data-marker="item-location"]`, а при их отсутствии —
`itemprop`/классы и разбор ссылки. Если карточки не найдены и это не пустая выдача,
приложение сохраняет скриншот `logs/screenshots/no_cards_*.png` и пишет предупреждение.

Запасные варианты при изменении вёрстки:

1. Открыть сохранённый скриншот и DevTools на живой странице.
2. Обновить селекторы в `scraper.py` (JS `_EXTRACT_JS` и `CARD_SELECTOR`).
3. Если Avito перестал показывать просмотры в списке, значение остаётся пустым, а в
   таблице отображается «нет».
4. При капче снизить частоту запусков и увеличить паузы; прокси и обход капчи не
   предусмотрены.

## Структура

```
main.py          — запуск GUI и офлайн-демо
gui.py           — окно CustomTkinter, карточки запросов, режимы, поток сбора
config.toml      — настройки, пути и [telegram].bot_token
scraper.py       — Playwright Chromium, поиск и извлечение карточек
filters.py       — локальные фильтры и модель QueryConfig
storage.py       — SQLite: saved_queries, listings, price_history, seen_ids, subscribers
notifier.py      — sendMessage, русские шаблоны уведомлений
reporter.py      — XLSX и сортируемая таблица
bot_listener.py  — long polling /start, upsert chat_id + @username
utils.py         — конфиг, даты, цены, логирование, транслитерация
run.bat          — запуск приложения без активации venv
install_browser.bat — установка Chromium в папку проекта
cloudflare-worker/ — готовый Telegram Bot API reverse proxy для blocked-сетей
requirements.txt
README.md
```

Рабочие каталоги создаются автоматически: `data/`, `logs/`, `logs/screenshots/`, `exports/`.

## Возможные проблемы

- **`EPERM: operation not permitted, mkdir ...ms-playwright`** — Windows не разрешает
  установку браузера в `AppData`. Запустите `install_browser.bat`: Chromium будет сохранён
  в `.playwright-browsers` проекта, а приложение найдёт его автоматически.
- **`Executable doesn't exist`** — выполните `install_browser.bat` или
  `python -m playwright install chromium`.
- **Telegram 401/Неверный токен** — проверьте `[telegram].bot_token`, сохраните токен заново.
- **`chat not found`** — получатель ещё не отправил `/start` этому боту.
- **Список получателей не обновляется** — посмотрите статус под блоком «Получатели».
  Если написано «токен не задан», слушатель Telegram не работает и `/start` не принимается.
  Сохраните токен, дождитесь статуса «подключён», отправьте `/start` и нажмите
  «Обновить список». Если токен добавлен, но поле не принимает вставку, используйте кнопку
  «Вставить» или «Открыть config.toml».
- **Статус Telegram: ошибка / таймауты `api.telegram.org`** — проверьте интернет и VPN.
  Приложение не использует прокси и повторяет подключение каждые 30 секунд.
- **Таблица «Подходящие» пуста, хотя браузер нашёл объявления** — откройте вкладку
  «Не подходящие» и посмотрите причины. Например, Avito мог вернуть соседние города или
  не указать город; для города теперь действует мягкий режим. Также проверьте обязательные
  слова: должны совпасть все.
- **Файл XLSX не сохраняется** — закройте его в Excel и повторите экспорт.
- **Капча Avito** — пройдите её в автоматически показанном окне Chromium и не запускайте
  приложение слишком часто; прокси не используются.
- **Долгая остановка** — пауза 5–10 секунд прерывается сразу, но текущая навигация Playwright
  может завершаться до своего таймаута; дождитесь остановки.
